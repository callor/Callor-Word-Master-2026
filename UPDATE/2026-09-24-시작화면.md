# 시작화면 UI 개선 요청

1. 지금은 프로젝트가 시작하면 곧바로 단어들이 떨어지는 화면이 나타나고 있다.
2. 처음 시작 화면이 뭔가 게임적인 요소로 시작하면 좋겠어
3. 디자인 적인 요소를 적용해서 시작화면을 개선해줘

## 처리 결과 — 2026-09-24

처리 대상: `Callor-Word-Master-v1` · 담당: 두기(Doogie)

### 처리 내용

- 앱 첫 화면을 게임 로비로 변경했습니다. 짙은 초록색 배경, 강조색, 움직이는 단어 카드와 키보드 연출을 적용했습니다.
- 게임 시작 버튼을 누른 뒤에만 게임을 실행합니다. 시작 화면 대기 중에는 단어 낙하와 생명 차감이 발생하지 않습니다.
- 영단어 입력 → 한글 뜻 입력 → 점수 획득의 3단계 안내와 게임 정보를 추가했습니다.
- PC와 모바일에 대응하는 레이아웃, 키보드 포커스 표시, 움직임 줄이기 설정 대응을 추가했습니다.
- 게임 상단에 시작 화면으로 돌아가는 버튼을 추가했습니다. 돌아가면 현재 플레이는 종료되며 다시 시작하면 새 게임으로 진입합니다.
- 재시작 시 화면상 생명 3개와 실제 판정 5개가 불일치하던 부분을 `MAX_LIVES`로 통일했습니다.
- 원본 v0.1.8-Final은 수정하지 않았습니다.

### 검증 결과

- `npm run lint`: 통과
- `npm run build`: TypeScript 7.0.2 타입 검사 및 배포용 빌드 통과
- 로컬 서버: 페이지 HTTP 200, JavaScript/CSS 자원 8개 정상 응답
- 초기 HTML: 로비와 게임 시작 버튼 존재, 게임 입력창과 낙하 영역 미포함 확인
- 실제 브라우저 클릭, 한글 입력, 화면 배치 및 모바일 조작: 브라우저 자동화 환경 오류로 미검증
