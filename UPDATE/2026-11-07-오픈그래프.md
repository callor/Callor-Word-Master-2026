# 페이지 오픈그래프 적용

## 요청

페이지에 링크 공유용 오픈그래프 적용. 사용자 지정 서비스 주소: https://word.callor.com

## 처리 결과 — 2026-11-07

- Next.js Metadata API로 Open Graph 제목, 설명, URL, 사이트명, 한국어 locale, website 유형을 설정했습니다.
- 기존 포트폴리오 커버를 공개 정적 경로에 복사하여 대표 이미지로 사용했습니다. 원본은 수정하지 않았습니다.
- 이미지의 실제 크기 1536×1024와 대체 설명을 메타데이터에 추가했습니다.
- X(Twitter)의 summary_large_image 카드도 설정했습니다.
- 기본 서비스 주소는 https://word.callor.com이며, 다른 배포 환경에서는 빌드 전에 SITE_URL로 변경할 수 있습니다.
- 운영 서버 배포와 공유 플랫폼의 실제 미리보기/캐시 갱신은 수행하지 않았습니다.

## 검증 결과

- npm run lint: 통과.
- TypeScript 7 타입 검사: 통과.
- npm run build: Turbopack의 globals.css 처리용 하위 Node 프로세스 종료로 실패. 권한 승격 재시도에서도 동일 오류. 원인은 확정하지 않았습니다.
- npm run build -- --webpack: 성공. 기본 build 스크립트는 변경하지 않았습니다.
- 생성된 .next/server/app/index.html에서 og:title, og:description, og:url, og:site_name, og:locale, og:type, og:image와 이미지 크기/설명, twitter:card 및 이미지 태그 확인.
- og:image가 https://word.callor.com/images/word-master-og.png의 절대 URL로 출력됨을 확인.
- 복사된 이미지와 원본의 SHA-256 일치 확인.
- 기본 Turbopack 빌드 오류 및 운영 배포 후 실제 공유 미리보기 검증은 후속 확인 사항입니다.

## 운영 반영

현재 환경에서는 npm run build -- --webpack으로 검증된 빌드를 만들 수 있습니다. 운영 서비스에 소스와 public 이미지를 반영하고 해당 환경의 배포 절차에 따라 빌드·재시작해야 합니다. 환경변수 SITE_URL을 사용하는 경우 빌드 전에 설정합니다. 기존 공유 미리보기가 남아 있으면 해당 플랫폼의 캐시를 갱신해야 할 수 있습니다.
