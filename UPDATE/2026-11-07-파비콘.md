# 프로젝트 파비콘 생성 및 적용

## 요청

Word Master 프로젝트에 어울리는 파비콘 이미지 생성.

## 처리 내용 — 2026-11-07

- 내장 이미지 생성 도구로 짙은 초록색 배경과 라임색 불꽃, W 형태를 결합한 아이콘을 생성했습니다.
- 생성 원본은 포트폴리오 폴더에 저장했습니다.
- 디자인 변경 없이 배포용 크기와 ICO 형식으로 변환했습니다.
- Next.js 파일 기반 아이콘 규칙에 따라 브라우저 파비콘과 PNG 및 Apple 홈 화면 아이콘을 적용했습니다.
- 기존 파비콘은 백업했습니다. 운영 사이트 배포는 수행하지 않았습니다.

## 생성 프롬프트

Create one square favicon app icon for Callor Word Master, a Korean English typing arcade learning game. Flat graphic icon, bold simple silhouette readable at 16x16. Full-bleed solid deep forest green #101f19 square background. A centered large vibrant lime #d8ff67 stylized flame emblem, its inner cutout subtly forms a broad W shape suggestive of Word, but no actual typography. Flame occupies 72 percent of canvas with generous safe margins. One solid shape, minimal geometric rounded curves, strong contrast. No gradients, no glow, no shadows, no border, no tiny details, no particles, no words, no mockup. Crisp premium vector-like raster artwork. 1024x1024 square.

## 검증

- 생성 이미지 및 512px 변환 이미지 시각적 확인 완료.
- 운영 브라우저의 아이콘 표시 및 캐시 갱신은 미검증이며 배포 후 확인 필요.

- ESLint 및 TypeScript 7 검사 통과.
- npm run build -- --webpack 성공. 앞선 작업에서 확인된 Turbopack 오류로 검증용 Webpack 빌드를 사용했으며 기본 스크립트는 유지했습니다.
- 생성 HTML의 favicon.ico, icon.png, apple-icon.png 링크 확인.
- ICO 내부 16/32/48/256px 이미지 및 PNG 512px, Apple 180px 크기 확인.

## 후속 수정 — ICO RGBA 오류 (2026-11-07)

### 추가 요청

npm run build에서 favicon.ico의 `The PNG is not in RGBA format!` 오류 발생.

### 원인 및 처리

- 이전 생성 과정에서 ICO 내부 PNG가 RGB 3채널로 저장된 반면 ICO 항목은 32비트로 선언되었습니다. Webpack 검증만으로 Turbopack의 RGBA 요구사항을 확인하지 못했습니다.
- 기존 디자인 원본을 사용해 16·32·48·256px 각 PNG를 ensureAlpha() 및 palette:false 옵션으로 RGBA 4채널로 생성하여 ICO를 다시 구성했습니다.
- 각 PNG의 채널 수 4와 PNG IHDR color type 6(RGBA)을 확인했습니다.
- TypeScript 7 및 기본 빌드 스크립트는 변경하지 않았습니다.

- 이 오류는 첨부된 ICO RGBA 형식 오류와 구분됩니다. 운영 배포 및 사용자 환경에서의 기본 빌드 재확인은 미완료입니다.
- 수정된 ICO를 포함한 npm run build -- --webpack 빌드는 성공했습니다.
