# Callor Word Master

## 요구사항

> 회화에서 많이 사용하는 단여 200개 정도를 미리 포함해 주면 좋겠어

## 응답

좋습니다. **Callor Word Master 기본 단어 데이터로 회화에서 자주 사용하는 영단어 200개를 미리 포함**하겠습니다.

단순히 200개를 나열하지 않고 게임과 암기에 적합하도록 다음처럼 구성하는 것이 좋습니다.

## 기본 단어 구성

| 분류               | 수량 | 예시                              |
| ------------------ | ---: | --------------------------------- |
| 핵심 동사          | 60개 | go, come, get, make, take, know   |
| 일상 명사          | 55개 | time, people, work, home, food    |
| 형용사             | 40개 | good, different, important, ready |
| 부사·전치사·기능어 | 30개 | always, often, together, before   |
| 회화 핵심 단어     | 15개 | please, thanks, sorry, welcome    |

총 200개로 구성하겠습니다.

## 단어별 저장 정보

```ts
{
  english: "get",
  partOfSpeech: "VERB",
  difficulty: "BEGINNER",
  meanings: [
    "얻다",
    "받다",
    "도착하다",
    "이해하다"
  ],
  example: "I get home at six.",
  exampleMeaning: "나는 6시에 집에 도착한다.",
  isActive: true
}
```

게임에서는 `get`을 정확히 입력하면 다음 뜻 중 하나만 무작위로 표시됩니다.

```text
get
 ↓
"받다"
```

사용자가 `받다`를 한글로 입력하면 클리어됩니다. 다음에 `get`이 다시 출제될 때는 직전에 사용한 `받다`의 선택 확률을 낮추고 `얻다`, `도착하다`, `이해하다`가 먼저 선택되도록 하겠습니다.

## 난이도 구성

- `BEGINNER`: 100개
- `ELEMENTARY`: 60개
- `INTERMEDIATE`: 40개

초기 사용자는 쉬운 단어부터 시작하고, 누적 클리어 수에 따라 다음 난이도를 해제하도록 설계할 수 있습니다.

## Prisma Seed 적용

200개 단어는 다음 파일에 포함하겠습니다.

```text
prisma/
├── schema.prisma
├── seed.ts
└── data/
    └── conversation-words.ts
```

초기 데이터는 다음 명령으로 등록할 수 있게 구성합니다.

```bash
npx prisma migrate dev
npx prisma db seed
```

재실행해도 같은 단어가 중복 등록되지 않도록 `upsert` 방식으로 작성하겠습니다.

한글 뜻과 예문은 특정 사전 문장을 복사하지 않고 프로젝트용으로 직접 작성해 저작권 문제도 피하겠습니다. 이제 프로젝트를 생성할 때 **반응형 게임 프로토타입과 기본 회화 단어 200개 Seed 데이터**를 함께 포함하면 됩니다.
