# Callor Word Master

## Update 0.1.2 요구사항

훌륭해

1. PC 화면에서 게임창을 최대한 크게 했으면 좋겠어
2. 영문, 한글 글자크기를 12point 정도로 조정 해 보면 어떨까? 조금 부담스럽게 보여
3. 또는 기본 크기 12point 로 하고 글자크기를 선택 하게 할 수 있을까? 시력이 좋지 않은 사람도 있으니까
4. 내려오는 단어가 너무 느려서 박진감이 없어 조금만 더 빨랐으면 좋겠어
5. 내려오는 단어의 개수를 5이상으로 더 많았으면 좋겠어
6. 같은 단어가 너무 자주 등장해
7. 왼쪽의 "원하는 단어부터.." 브렌드 이미지 명칭으로 바꾸면 좋겠어

## 요청하신 개선 사항을 적용한 v0.1.3 패키지입니다.

[Callor-Word-Master-v0.1.3-Phase1](../Callor-Word-Master-v0.1.3-Phase1/)

주요 변경 사항:

- PC 중앙 게임 영역과 낙하 영역 확대
- 영문·한글 기본 크기를 모두 `12pt`로 조정
- `10·12·15·18pt` 글자 크기 선택 기능 추가
- 선택한 크기를 `localStorage`에 저장
- 낙하 속도를 약 35~40% 향상
- 동시 낙하 단어를 3개에서 6개로 확대
- 최근 출제 단어 30개를 기억해 반복 출제 억제
- 왼쪽 문구를 `Callor Word Master` 브랜드 영역으로 변경
- 모바일·태블릿 반응형 구조 유지

기존 데이터베이스와 Prisma 스키마에는 변경이 없으므로 마이그레이션과 Seed를 다시 실행할 필요는 없습니다.

```bash
cd callor-word-master
npm install
npm run dev
```
