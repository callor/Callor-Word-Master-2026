# Callor Word Master

## 3차 요구사항

```text
1. 프로젝트 이름은 Callor Word Master 로 하면 좋겠고
2. 데이베이스는 PostgreSQL 을 사용하려고해
3. 당연 Prisma 를 사용하면 좋겠고
4. Google, github Login 포함하면 좋겠고 향후 Kakao, Naver Login 도 포함할 수 있도록해줘
5. Web 과 스마트기기도 고려한 반응형 Layout 으로 설계

나머지는 추천한 방식으로
```

좋습니다. 프로젝트의 기술 방향이 명확하게 확정됐습니다.

## 반응형 화면 설계

게임 화면은 기기별로 별도 구현하지 않고 하나의 반응형 레이아웃으로 구성합니다.

### 데스크톱

```text
┌─────────────────────────────────────────────┐
│ Logo       점수  콤보  포인트      사용자  │
├─────────────────────────────────────────────┤
│                                             │
│               낙하 게임 영역                │
│                                             │
│                    apple                    │
│                                             │
│ ─────────────── 위험선 ─────────────────── │
├─────────────────────────────────────────────┤
│ 단계 1/2  [ 영단어를 입력하세요         ] │
└─────────────────────────────────────────────┘
```

### 스마트폰·태블릿

- 헤더 정보를 한 줄로 축소
- 메뉴는 햄버거 또는 하단 내비게이션 사용
- 입력창은 화면 하단에 고정
- 가상 키보드가 나타나도 입력창이 가려지지 않도록 처리
- 게임 영역은 남은 화면 높이를 자동으로 사용
- 불꽃 효과는 기기 성능과 화면 크기에 맞게 조절
- 가로·세로 화면 모두 지원

권장 화면 기준은 다음과 같습니다.

- 스마트폰: `360px` 이상
- 태블릿: `768px` 이상
- 데스크톱: `1024px` 이상
- 대형 화면: 게임 영역 최대 너비 제한

## 인증 정책

소셜 로그인만으로는 “최초 회원가입자” 판정이 동시에 발생할 수 있으므로 다음 방식으로 처리합니다.

1. OAuth 로그인 성공
2. Auth.js가 사용자 계정을 생성
3. 데이터베이스 트랜잭션에서 기존 사용자 존재 여부 확인
4. 최초 사용자이면 `ADMIN`
5. 이후 사용자는 `USER`
6. 이메일이 같은 다른 로그인 공급자는 기존 계정과 안전하게 연결

관리자 여부는 화면에서만 검사하지 않고 서버 작업에서도 반드시 다시 확인합니다.

## 단어 데이터 구조

복수 한글 뜻을 확장성 있게 관리하기 위해 별도 테이블을 사용합니다.

```text
Word
 ├── apple
 └── WordMeaning
      ├── 사과
      └── 사과나무 열매
```

게임이 시작되면 서버가 뜻 하나를 무작위로 선택합니다. 같은 단어가 연속으로 출제될 경우 직전 뜻을 우선 제외하도록 설계하겠습니다.

```prisma
model Word {
  id          String        @id @default(cuid())
  english     String        @unique
  difficulty  Difficulty    @default(BEGINNER)
  fallSpeed   Int           @default(30)
  isActive    Boolean       @default(true)
  meanings    WordMeaning[]
  createdAt   DateTime      @default(now())
  updatedAt   DateTime      @updatedAt
}

model WordMeaning {
  id        String   @id @default(cuid())
  wordId    String
  meaning   String
  word      Word     @relation(fields: [wordId], references: [id], onDelete: Cascade)
  createdAt DateTime @default(now())

  @@unique([wordId, meaning])
}
```

## 1차 개발 범위

첫 번째 버전에서는 다음 범위까지 완성하는 것이 좋습니다.

- 반응형 기본 레이아웃
- 라이트·다크·시스템 테마
- 영단어 낙하 애니메이션
- 영문 입력 판정
- 복수 뜻 중 하나 무작위 표시
- 한글 타이핑 판정
- 불꽃 제거 효과
- 임시 점수 계산
- PC·태블릿·스마트폰 대응

이 단계에서는 인증과 PostgreSQL을 연결하기 전에 임시 단어 데이터로 게임의 핵심 재미와 조작감을 먼저 검증합니다.

그다음 PostgreSQL·Prisma·Auth.js·관리자 단어 관리·포인트 저장 기능을 순차적으로 연결하면 됩니다. 이제 바로 **Callor Word Master Next.js 프로젝트의 기반 구조와 1차 게임 프로토타입 생성**부터 시작하면 좋겠습니다.
