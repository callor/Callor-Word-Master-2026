# 프로젝트 시작

## 요구사항

프로젝트를 어떻게 진행하면 좋을지 계획을 세워줘

## 첫 번째 목표

좋습니다! 가장 먼저 해야 할 일은 화면 디자인이 아니라 **게임의 핵심 동작을 검증하는 MVP**를 만드는 것입니다.

회원가입이나 관리자 기능보다 먼저 아래 게임 루프가 실제로 재미있게 작동하는지 확인하는 것이 좋습니다.

1. 영단어가 화면 위에서 아래로 내려오기
2. 사용자가 영단어 입력
3. 정답이면 복수 한글 뜻 중 하나를 무작위로 표시
4. 표시된 한글 뜻 입력
5. 정답이면 불꽃 효과와 함께 제거
6. 10점 추가
7. 다음 단어 출제

처음에는 데이터베이스 없이 다음과 같은 임시 데이터로 구현해도 됩니다.

```ts
const words = [
  {
    english: "apple",
    meanings: ["사과", "사과나무 열매"],
  },
  {
    english: "run",
    meanings: ["달리다", "운영하다", "작동하다"],
  },
  {
    english: "bright",
    meanings: ["밝은", "영리한", "환한"],
  },
];
```

## 권장 개발 순서

### 1단계: 프로젝트 기본 구조

- Next.js App Router
- TypeScript
- Tailwind CSS
- ESLint
- 기본 라이트·다크 테마
- 프로젝트 패키지 구조

### 2단계: 게임 프로토타입

우선 한 화면에서 단어 하나만 떨어지도록 만듭니다.

```text
READY
  ↓
영단어 낙하
  ↓
영문 입력
  ↓
한글 뜻 무작위 표시
  ↓
한글 입력
  ↓
불꽃 효과
  ↓
점수 지급
  ↓
다음 단어
```

이 단계에서는 로그인과 데이터베이스를 연결하지 않습니다. 점수도 React 상태에만 저장합니다.

### 3단계: 데이터베이스 설계

게임이 정상 작동한 다음 데이터베이스를 연결합니다.

핵심 테이블은 다음 정도로 시작하면 됩니다.

- `users`: 회원 및 권한
- `words`: 영단어와 난이도
- `word_meanings`: 단어별 복수 한글 뜻
- `play_sessions`: 게임 실행 기록
- `word_attempts`: 단어별 입력 결과
- `point_ledger`: 포인트 지급 이력

복수 뜻은 JSON 배열보다 별도의 `word_meanings` 테이블로 관리하는 것을 권장합니다. 검색·수정·통계·뜻별 학습 이력 확장이 편해집니다.

### 4단계: 회원가입과 권한

- Auth.js(NextAuth) 적용
- 회원가입 및 로그인
- 최초 가입자 `ADMIN`
- 이후 가입자 `USER`
- `/admin` 접근 통제

### 5단계: 관리자 단어 관리

- 영단어 등록
- 한글 뜻 여러 개 추가·삭제
- 난이도 설정
- 출제 활성화
- 단어 검색 및 수정

### 6단계: 포인트와 기록

- 완전 클리어 시 10점
- 중복 지급 방지
- 누적 포인트 표시
- 최근 게임 기록
- 단어별 성공·실패 기록

## 지금 결정하면 좋은 항목

개발을 시작하려면 우선 다음 네 가지를 확정하면 됩니다.

1. 프로젝트 및 서비스 이름
2. 데이터베이스: MySQL 또는 PostgreSQL
3. ORM: Prisma 사용 여부
4. 로그인: 이메일·비밀번호만 할지 Google 로그인도 포함할지

현재 사용자님의 개발 환경을 고려하면 다음 구성을 추천합니다.

- 프로젝트 가칭: `Callor Typing`
- 프레임워크: Next.js + TypeScript
- UI: Tailwind CSS
- 인증: Auth.js 이메일·비밀번호 방식
- 데이터베이스: MySQL
- ORM: Prisma
- 패키지 관리자: npm
- 1차 개발 대상: 데스크톱 웹
- 이후 확장: 태블릿 반응형 및 PWA

따라서 다음 작업은 **Next.js 프로젝트를 생성하고, 데이터베이스 없이 핵심 게임 화면부터 구현하는 것**이 가장 좋습니다. 첫 번째 결과물은 영단어가 내려오고 영문과 한글 입력을 모두 완료하면 사라지는 실행 가능한 프로토타입입니다.
