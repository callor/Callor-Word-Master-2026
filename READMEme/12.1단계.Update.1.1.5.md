# Callor Word Master

## Update 0.1.5 요구사항

1. 화면 좌우의 메시지박스(??)는 살려 놓고 전체화면을 꽉차게 만들어줘
2. Footer를 화면에 고정하고 "CopyRight HanQube Solution callor@callor.com" 문구를 넣어줘
3. 영단어, 한글 풀이를 모두 맞추면 단어가 폭팔하듯 없어지게

요청하신 기능을 적용한 v0.1.5 패키지입니다.

[Callor-Word-Master-v0.1.5-Phase1](../Callor-Word-Master-v0.1.5-Phase1/)

변경 사항:

- 게임창은 PC 화면 전체 폭과 높이를 계속 사용
- 왼쪽 브랜드와 오른쪽 상태 박스를 반투명 오버레이로 복원
- 좌우 박스가 게임 영역의 실제 크기를 줄이지 않도록 처리
- Footer를 화면 하단에 고정
- Footer 문구 추가:
  `CopyRight HanQube Solution · callor@callor.com`
- 이메일 클릭 시 메일 작성 가능
- 영단어와 한글 뜻 정답 완료 시 단어가 순간적으로 팽창
- 섬광과 원형 충격파 적용
- 16개 불꽃 파티클이 사방으로 확산
- 단어가 회전·축소·블러 효과와 함께 폭발하듯 소멸
- 모바일 Footer도 간결한 형태로 유지

데이터베이스 변경은 없으므로 마이그레이션이나 Seed를 다시 실행할 필요는 없습니다.
