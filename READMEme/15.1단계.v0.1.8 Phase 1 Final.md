# Callor Word Master

## 1단계 최종 본

루미가 요청사항을 모두 반영한 1단계 최종버전을 완성했습니다.

[Callor Word Master v0.1.8 Phase 1 Final 다운로드](sandbox:/workspace/scratch/84dfd0de127a/Callor-Word-Master-v0.1.8-Phase1-Final.zip)

주요 추가 사항:

- 생명 소진 시 게임 오버·최종 결과·재시작
- 화면 이탈 시 자동 일시정지
- 최초 실행 게임 방법 안내
- 소리·폭발 효과 설정 및 `localStorage` 저장
- 브라우저 전체화면
- 모바일 정답 진동 피드백
- 기존 반응형 3열 레이아웃과 200개 회화 단어 유지
- 버전 `v0.1.8 · Phase 1 Final`

검증도 완료했습니다.

- ESLint 통과
- TypeScript 타입 검사 통과
- Prisma 스키마 검사 통과
- ZIP 압축 무결성 검사 통과

압축을 푼 다음 아래 명령으로 실행하면 됩니다.

```bash
npm install
npm run dev
```

이번 변경에는 데이터베이스 스키마 변경이 없으므로 기존 DB를 사용한다면 별도의 마이그레이션은 필요하지 않습니다.
