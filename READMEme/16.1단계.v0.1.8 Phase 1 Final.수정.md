# Callor Word Master

## 1단계 최종 본 수정

> 단어를 3개 놓치면 게임이 끝나는데 좀더 늘리고 싶으면 어느부분을 수정하면 될까

현재 생명 수 `3`이 여러 곳에 직접 입력되어 있습니다. 가장 좋은 방법은 상단에 최대 생명 상수를 만들고 모두 이 값을 사용하도록 변경하는 것입니다.

[src/components/game/word-game.tsx](sandbox:/workspace/scratch/84dfd0de127a/callor-word-master/src/components/game/word-game.tsx)에서 다음과 같이 수정하세요.

```tsx
const PLAY_WORDS = conversationWords.filter((word) => word.difficulty === "BEGINNER");

const MAX_LIVES = 5;
```

그리고 기존 생명 관련 숫자 `3`을 다음처럼 변경합니다.

```tsx
const [lives, setLives] = useState(MAX_LIVES);
```

```tsx
const livesRef = useRef(MAX_LIVES);
```

`resetGame()` 안에서도 변경합니다.

```tsx
setLives(MAX_LIVES);
livesRef.current = MAX_LIVES;
```

화면의 생명 표시도 변경해야 합니다.

기존:

```tsx
<strong className="lives" aria-label={`남은 기회 ${lives}`}>
  {"●".repeat(lives)}
  {"○".repeat(Math.max(0, 3 - lives))}
</strong>
```

변경:

```tsx
<strong className="lives" aria-label={`남은 기회 ${lives}`}>
  {"●".repeat(lives)}
  {"○".repeat(Math.max(0, MAX_LIVES - lives))}
</strong>
```

이제 다음 값 하나만 바꾸면 생명 수를 조절할 수 있습니다.

```tsx
const MAX_LIVES = 5; // 5개 놓치면 게임 종료
```

예를 들어 10개까지 허용하려면 다음처럼 설정하면 됩니다.

```tsx
const MAX_LIVES = 10;
```

다만 PC와 스마트폰 화면에서 생명 아이콘이 너무 길어질 수 있으므로, 6개 이상이라면 점 표시 대신 다음처럼 숫자로 표시하는 방식도 좋습니다.

```tsx
<strong className="lives">
  LIFE {lives} / {MAX_LIVES}
</strong>
```
