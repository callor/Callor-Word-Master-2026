# Callor Word Master

## Update 0.1.1 요구사항

네오루미!!
아주 훌륭해 그런데 몇가지 추가사항이 있어

1. 영어 단어가 너무 크게 보여, 영어 단어 크기를 15point 정도로 하면 좋겠어
2. 한글 단어는 12point 정도로 해보면 좋겠어
3. 단어가 동시에 여러개가 나타 나고 그중 선택적으로 입력하여 맞추도록 했으면 좋겠어

네오루미가 요청하신 내용을 모두 반영했습니다.

[Callor-Word-Master-v0.1.1-Update](../Callor-Word-Master-v0.1.1-Update)

변경 사항:

- 영단어 크기: `15pt`
- 한글 뜻 크기: `12pt`
- 영단어 3개 동시 낙하
- 사용자가 원하는 영단어를 입력하여 선택
- 선택된 단어에만 무작위 한글 뜻 표시
- 한글 뜻까지 입력하면 해당 단어만 불꽃과 함께 제거
- 제거된 위치에 새로운 단어 자동 보충
- 선택하지 않은 다른 단어는 계속 낙하
- 여러 단어를 놓친 경우 생명과 실패 기록 동시 반영
- PC·태블릿·스마트폰 반응형 구조 유지

기존 PostgreSQL 데이터베이스와 200개 단어 Seed 구조는 변경하지 않았으므로 DB를 다시 만들 필요는 없습니다.

기존 프로젝트를 교체한 경우 실행하면 됩니다.

```bash
cd callor-word-master
npm install
npm run dev
```

코드 검사, TypeScript 검사, Prisma 스키마, 200개 단어와 다중 낙하 설정 검증을 완료했습니다.
