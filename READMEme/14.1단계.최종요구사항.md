# Callor Word Master

## 1단계 최종

네, 지금 상태라면 **1단계 핵심 게임 프로토타입은 충분히 완성된 수준**입니다. 기능을 더 늘리기보다 안정화하고 2단계로 넘어가는 것이 좋겠습니다.

다만 1단계를 마감하기 전에 다음 세 가지는 추가하는 것을 권장합니다.

1. 생명 종료 처리

현재 생명이 0이 되어도 게임이 계속 진행될 수 있으므로 다음 흐름이 필요합니다.

```text
생명 0
→ 모든 단어 낙하 정지
→ GAME OVER 표시
→ 최종 점수·클리어·정확도 표시
→ 다시 시작 버튼
```

2. 브라우저 상태 대응

게임 도중 다른 탭으로 이동하거나 브라우저가 비활성화되면 자동으로 일시정지해야 합니다. 그렇지 않으면 돌아왔을 때 단어를 모두 놓칠 수 있습니다.

```ts
document.addEventListener("visibilitychange", () => {
  if (document.hidden) {
    // 게임 자동 일시정지
  }
});
```

3. 게임 설정 저장

현재 글자 크기처럼 다음 설정도 `localStorage`에 저장하면 좋습니다.

- 테마
- 글자 크기
- 효과음 사용 여부
- 폭발 애니메이션 사용 여부
- 마지막 선택 난이도

## 선택적으로 추가할 기능

다음 기능은 유용하지만 2단계 이후로 미뤄도 됩니다.

- 정답·오답 효과음
- 배경음악
- 실제 전체화면 전환 버튼
- 동시 출제 단어 수 선택
- 낙하 속도 난이도 선택
- 영문·한글 입력 정확도 분리
- 단어별 반응 시간 측정
- 처음 사용자를 위한 3단계 튜토리얼
- 모바일 진동 피드백
- 키보드 한·영 상태 안내 강화

## 1단계 완료 기준

현재 구현된 범위는 다음과 같습니다.

- 다중 영단어 낙하
- 무작위 단어·위치·속도·등장 간격
- 원하는 영단어 선택 입력
- 복수 한글 뜻 중 무작위 출제
- 영문·한글 타자연습
- 점수·콤보·생명·정확도
- 단어 폭발 효과
- 글자 크기 선택
- 라이트·다크 테마
- PC·태블릿·스마트폰 반응형 화면
- PostgreSQL·Prisma 기반
- 회화 단어 200개
- 좌우 정보 패널과 중앙 게임 영역 분리

따라서 **게임 오버, 자동 일시정지, 기본 설정 저장**까지만 보완하면 1단계를 공식 마감해도 좋겠습니다.

그다음 2단계에서는 다음 순서로 진행하는 것이 적절합니다.

1. Auth.js 적용
2. Google·GitHub 로그인
3. 최초 가입자 관리자 권한
4. PostgreSQL에 사용자와 게임 기록 저장
5. 관리자 영단어·한글 뜻 CRUD
6. PointLedger 기반 포인트 관리
7. 개인 기록과 랭킹 화면

제 판단으로는 새로운 게임 기능을 더 넣기보다, 위의 세 가지 마감 기능을 반영한 **v0.1.8 Phase 1 Final**을 만든 다음 2단계로 넘어가는 것이 가장 좋습니다.
