# Callor Word Master

## Update 0.1.2 요구사항

1. 타이핑을 완료하고 Enter를 누르면 입력창에 포커스가 되었다 안되었다 하는 문제가 있어
2. 영문(단어) 입력상태와 한글(풀이) 입력을 할때 키보드 상태(한,영)를 자동으로 변경해 주면 좋겠어

요청하신 문제를 수정한 v0.1.2 패키지입니다.

[Callor-Word-Master-v0.1.2-Phase1](../Callor-Word-Master-v0.1.2-Phase1/)

적용 내용:

- 영문 입력 후 한글 입력 단계로 전환할 때 포커스 유지
- 오답 후 입력창 포커스 자동 복구
- 정답·새 단어 생성·일시정지 해제 후 포커스 복구
- 모바일 Enter 입력 후 발생하는 포커스 이탈 보완
- 영문 단계에서 `lang="en"` 적용 및 `ENG` 표시
- 한글 단계에서 `lang="ko"` 적용 및 `한글` 표시
- 모바일 키보드용 `enterKeyHint` 적용

다만 웹 브라우저에서는 보안 정책 때문에 Windows나 스마트폰의 실제 한/영 입력기를 강제로 전환할 수 없습니다. 따라서 단계별 언어 속성과 안내 배지는 자동으로 전환되지만, 운영체제의 한/영 전환은 사용자가 수행해야 합니다.

기존 데이터베이스와 Prisma 구조는 변경되지 않았으므로 마이그레이션이나 Seed를 다시 실행할 필요는 없습니다.
