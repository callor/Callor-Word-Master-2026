원인은 명확합니다. Prisma 연결 설정에는 문제가 없지만, PostgreSQL 서버에 `callor_word_master` 데이터베이스가 아직 생성되지 않았습니다.

다음 순서로 진행해 주세요.

## 1. `.env` 확인

프로젝트 루트의 `.env`를 실제 PostgreSQL 계정에 맞게 수정합니다.

```env
DATABASE_URL="postgresql://postgres:비밀번호@localhost:5432/callor_word_master?schema=public"
```

비밀번호에 `@`, `#`, `%`, `!` 같은 특수문자가 있으면 URL 인코딩해야 합니다.

## 2. 데이터베이스 생성

Git Bash에서 다음 명령을 실행합니다.

```bash
psql -U postgres -h localhost -p 5432 -d postgres
```

비밀번호 입력 후 PostgreSQL 콘솔에서 실행합니다.

```sql
CREATE DATABASE callor_word_master
    WITH ENCODING 'UTF8'
    TEMPLATE template0;
```

생성 여부를 확인합니다.

```sql
\l
```

종료합니다.

```sql
\q
```

한 줄로 생성하려면 다음 명령도 가능합니다.

```bash
psql -U postgres -h localhost -p 5432 -d postgres \
  -c "CREATE DATABASE callor_word_master WITH ENCODING 'UTF8' TEMPLATE template0;"
```

## 3. Prisma 테이블 생성

데이터베이스를 만든 다음 프로젝트 폴더에서 실행합니다.

```bash
npm run db:generate
npm run db:migrate -- --name init
```

정상적으로 완료되면 PostgreSQL에 `Word`, `WordMeaning`, `User` 등의 테이블이 생성됩니다.

## 4. 기본 단어 200개 등록

```bash
npm run db:seed
```

성공하면 다음 메시지가 표시됩니다.

```text
Seeded 200 conversation words.
```

## 5. 데이터 확인

```bash
npm run db:studio
```

브라우저에서 Prisma Studio가 열리면 다음 내용을 확인합니다.

- `Word`: 200건
- `WordMeaning`: 200건 이상
- 각 영단어에 복수 한글 뜻 연결

정리하면 실행 순서는 다음과 같습니다.

```bash
# PostgreSQL DB 생성 후
npm run db:generate
npm run db:migrate -- --name init
npm run db:seed
npm run db:studio
```

현재 오류는 Seed 코드 문제가 아니라 **Seed를 실행할 대상 데이터베이스가 아직 없어서 발생한 `P1003` 오류**입니다.
