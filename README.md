## 프로젝트 목표

1. 이 게임의 목적은 영문, 한글 타이핑과 영단어 암기를 위한 것이다
2. 영어단어가 화면상단에서 아래로 천천히 내려오고,
3. 맨 아래쪽에는 단어 입력창이 있어 영어단어를 타자로 입력하여 맞춘다
4. 단어를 맞추면 해당하는 영어단어와 한글풀이가 같이 나타나다.
5. 영어 단어의 한글풀이(뜻)을 맞추면 내려오던 단어가 작은 불꽃을 내며 사라지는 게임이다.
6. NextJS 를 사용해서 프로젝트를 생성한다.
7. Next Auth 를 사용해서 회원가입과 로그인을 할 수 있다.
8. 최초 회원가입한 사용자는 관리자 권한을 취득한다.
9. 관리자로 로그인을 하면 새로운 단어를 영단어, 한글풀이를 입력 할 수 있어야 한다.
10. 영단어에 한글풀이(뜻)를 복수로 등록 할 수 있어야 하고, 랜덤으로 한개를 보여준다.
11. 일반 사용자는 단어를 1개 클리어 할때마다 포인트가 쌓이며 향후 포인트 사용 방법을 추가할 예정이다
12. 포인트를 어떻게 저장할지 현 시점에서는 결정되지 않았다.
13. 다크와 라이트 테마를 화면에서 선택 할 수 있고, 선택된 테마는 localStorage 에 저장해 두고 다시 게임을 시작하면 이전 테마로 시작한다.

주요 내용은 다음과 같습니다.

- 영단어 입력 → 한글 뜻 입력 → 불꽃 제거의 2단계 게임 구조
- Next.js App Router + TypeScript 기반 아키텍처
- Auth.js(NextAuth)를 이용한 회원가입·로그인
- 최초 가입자에게 관리자 권한을 안전하게 부여하는 방식
- 관리자 영단어·복수 한글 뜻·난이도 관리
- 일반 사용자 포인트 및 플레이 기록
- 라이트·다크·시스템 테마와 `localStorage` 저장
- 데이터베이스 엔터티와 API 초안
- 보안·접근성·테스트 기준
- 약 3~4주 분량의 MVP 개발 단계

포인트는 다음 구조를 권장했습니다.

- 단어 완전 클리어: 기본 10점
- `PointLedger`에 지급 이력 저장
- `User.totalPoints`에는 누적 포인트 저장
- `attemptId`에 UNIQUE 제약을 적용해 중복 지급 방지
- 시도 기록·포인트 원장·누적 포인트를 하나의 트랜잭션으로 처리
